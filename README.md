# Simulateur Fiscal Auto-Entrepreneur

Simulateur de charges et revenus nets pour auto-entrepreneurs en France.

🔗 **Live** → [tax-calculator-dusky-ten.vercel.app](https://tax-calculator-dusky-ten.vercel.app)

## Fonctionnalités

- Calcul automatique des cotisations sociales selon l'activité (BIC / BNC / commerce)
- Simulation du revenu net mensuel et annuel après charges
- Interface claire, responsive, utilisable sur mobile

## Stack

- React + TypeScript + Vite
- shadcn/ui + Tailwind CSS
- Déployé sur Vercel

## Lancer en local

```bash
npm install
npm run dev
```
